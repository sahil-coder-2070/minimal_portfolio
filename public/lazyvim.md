# 🚀 Neovim + LazyVim Beginner Cheat Sheet

> Leader Key = `Space`

---

# 📌 Basic Modes

| Mode | Kaise Jaaye | Purpose |
|------|-------------|----------|
| Normal Mode | `Esc` | Navigation & Commands |
| Insert Mode | `i` | Typing |
| Visual Mode | `v` | Select Text |
| Visual Line | `V` | Select Whole Lines |
| Command Mode | `:` | Commands Run Karna |

---

# 🎯 Recommended Learning Order

1. Navigation
2. Insert mode
3. Save/Quit
4. Copy/Paste/Delete
5. Telescope (`Space + ff`)
6. File explorer
7. Buffers
8. LSP & Plugins
